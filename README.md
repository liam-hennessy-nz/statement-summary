# statement-summary

A full stack bank statement summariser. Vite+React frontend, Spring Boot backend, PostgreSQL database.

# About

I have been wanting an app to group bank transactions by categories, but do not trust anything I have not built myself
for this. The idea is to get a better understanding of where money goes, and perhaps help to create better financial
habits. It is also a good excuse to have another project to work on, further developing my full stack skills. I know
different banks will have different statement export formats, but I will only focus on supporting the bank I use, at
least for now.
